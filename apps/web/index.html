FAQ

คำถามที่พบบ่อย

ต้องซื้อกล้องใหม่ไหม?
ไม่จำเป็น — ระบบรองรับกล้อง IP ที่ร้านมีอยู่แล้ว 9 ยี่ห้อ เช่น Hikvision, Dahua, Tapo, Imou, Reolink รวมถึงกล้อง RTSP ทั่วไป หรือแม้แต่กล้องโน้ตบุ๊กสำหรับทดลองใช้ ตัวเชื่อม (bridge) ติดตั้งบน mini PC เครื่องเดียวในร้าน
ระบบจดจำใบหน้าลูกค้าผิด PDPA หรือไม่?
ระบบออกแบบตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 โดยตรง — เก็บเฉพาะรหัสตัวเลขที่แปลงจากใบหน้า (face embedding) ไม่เก็บรูปภาพหรือวิดีโอ สมาชิกต้องให้ความยินยอมโดยชัดแจ้งก่อนสมัครพร้อมบันทึกหลักฐาน และถอนความยินยอม/ลบข้อมูลได้ทุกเมื่อที่หน้าร้าน ลูกค้าทั่วไปที่ไม่ใช่สมาชิก ระบบวิเคราะห์เพียงช่วงวัยและเพศโดยไม่เก็บตัวตน
ราคาเท่าไหร่?
ราคาช่วงเปิดตัวประมาณ 2,500 บาทต่อสาขาต่อเดือน รวมการจดจำสมาชิกไม่จำกัดครั้ง สคริปต์ขายจาก AI ระบบหลังบ้าน และการเชื่อมต่อ POS — เริ่มด้วย pilot ฟรีเพื่อพิสูจน์ผลก่อนได้ โทร 085-608-3298
เชื่อมต่อกับระบบ POS เดิมของร้านได้ไหม?
ได้ — POS ยิงยอดขายเข้าระบบผ่าน REST API ด้วย API key ประจำสาขา จับคู่สมาชิกด้วยเบอร์โทร จับคู่สินค้าด้วยบาร์โค้ด สินค้าที่ไม่รู้จักระบบสร้างให้อัตโนมัติ แต้มสะสมเข้าทันทีและพิมพ์ลงสลิปได้ รองรับทั้ง webhook, plugin และการนำเข้าท้ายวัน
ติดตั้งใช้เวลานานไหม?
ประมาณครึ่งวันต่อสาขา — ต่อกล้องที่มีอยู่เข้าระบบ ตั้ง mini PC ตัวเชื่อม เพิ่มกล้องจากหน้าเว็บ แล้วเทรนพนักงานใช้งานได้ใน 30 นาที ทีมงานช่วยติดตั้งและมีคู่มือให้
